Concepts (60-second read)

1 · Stage placement VAD and TTS local, STT and NLU remote; declared in config.PIPELINE and asserted by tests/unit/test_fallback.py.Pitfall: reordering the arm tables moves a stage across the network boundary unnoticed.
2 · Arms as data src/arms.py is the only interface, src/config.py the only table; arms named by HF repo id, repo/id@provider when two providers serve the same weights.Pitfall: if provider == "groq" leaking into feature code.
3 · Two logs, one turn_id runs/calls.jsonl = per call (cost, provider latency); runs/turns.jsonl = per turn (five-field split + time_to_first_audio).Pitfall: logging only calls — the 0.25–0.84 s device-open belongs to no model call.
4 · The budget misses on purpose Target < 2 s, measured 5.6–20.0 s (n=4). The budget column is kept as written so the miss stays visible.Pitfall: reading n=4 as a distribution — every stage varies 2–4× on identical input.
5 · Narrow fallback 429 / timeout / 5xx degrade to a local arm; 401, missing credential and an empty reasoning reply deliberately do not.Pitfall: a fallback turn compared against a clean one — hence fell_back and fallback_for.
6 · Cooldown A 429's Retry-After parks that arm (60 s default); in-memory and process-local by design.Pitfall: a doomed round-trip every turn turns a pace limit into a shut-off.
7 · Barge-in No kill, no second listener: Playback.abort() stops the device being handed samples, and the same listen() captures the interrupting utterance.Pitfall: open speakers — no AEC, so silero hears Kokoro and the reply cuts itself.
8 · Confirmation Read-back plus an affirmative labelled intent=confirm for every write action; max two re-asks, then abort and log.Pitfall: treating silence or a repeat of the command as consent.
